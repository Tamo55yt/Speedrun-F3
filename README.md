# Speedrun F3

**Speedrun F3** is a completely free, client-side Fabric mod built specifically for Minecraft speedrunners. It completely revamps the vanilla F3 debug screen, stripping away all the unnecessary performance stats and technical clutter, and leaving you with a clean, minimalist HUD that provides exactly what you need to achieve your next Personal Best.

## 🚀 Key Features

* **Minimalist & Clean Interface:** Features a slim, shadowed font with a transparent background that stays out of your way.
* **Entity Radar (E-Count):** Keep track of the Entity count to easily spot hidden Bastions and Nether Fortresses through walls.
* **Precise Facing & Angles:** Displays exact facing directions, perfect for accurate Stronghold triangulation.
* **Smart Coordinates & Portal Calculator:** Built-in Overworld-to-Nether coordinate converter (divides X and Z by 8) for blind travel.
* **Structure Navigation:** Pinpoint your location with clean Biome and Chunk boundaries.

## ⚙️ Compatibility
This mod is **Client-side only**. You can install it on your client and use it freely on any vanilla multiplayer server.
